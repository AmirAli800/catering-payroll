# مدیریت حقوق کترینگ

برنامه‌ای کاملاً مستقل برای ویندوز با رابط فارسی، نوشته‌شده با Python و Tkinter. این پروژه به سایت، Electron، مرورگر یا اینترنت وابستگی ندارد. اطلاعات کارکنان و پرداخت‌ها در یک پایگاه‌داده‌ی محلی SQLite روی رایانه ذخیره می‌شوند.

## امکانات

- ثبت و ویرایش پیک، آشپز و سایر کارکنان
- تعیین روز پرداخت ماهانه برای هر کارمند و یادآوری موعد حقوق
- ثبت و نمایش تاریخ شروع همکاری شمسی برای هر کارمند
- نمایش و ورود تاریخ‌ها به تقویم شمسی
- ثبت چند پرداخت علی‌الحساب برای هر کارمند در هر ماه
- محاسبه‌ی خودکار مانده‌ی حقوق و جلوگیری از پرداخت بیشتر از مانده
- مرور ماه‌های مختلف، جست‌وجوی کارکنان و دفتر پرداخت‌ها
- بایگانی کارمند از ماه انتخاب‌شده و امکان فعال‌سازی مجدد
- ویرایش یا حذف پرداخت اشتباه (مبلغ، تاریخ و یادداشت) از بخش ویرایش کارمند
- ثبت هزینه‌های خرید و اجاره همراه با شرح، مبلغ و تاریخ شمسی
- جمع هزینه‌های روزانه و ماهانه، همراه با نمودار مقایسه‌ی هفته و ماه جاری با دوره‌ی قبل
- رابط کاربری فارسی با تم سفید و طلایی، فونت Segoe UI در ویندوز و حرکت‌های نرم و کوتاه
- اسکرول یکپارچه‌ی کل صفحه‌ی هزینه‌ها با چرخ ماوس و تاچ‌پد، همراه با اندازه‌ی سازگار با صفحه‌نمایش
- نمایش تمام اعداد با رقم انگلیسی و جداکننده‌ی سه‌رقمی هنگام تایپ مبلغ
- نگه‌داری اطلاعات حتی پس از بستن برنامه

یادآوری موعد حقوق هنگام بازشدن برنامه و تا زمانی که برنامه در حال اجراست نمایش داده می‌شود؛ برای یادآوری در زمان بسته‌بودن برنامه، باید اجرای خودکار ویندوز تنظیم شود.

تاریخ شروع همکاری برای ثبت سابقه نگه‌داری می‌شود؛ حقوق ماهانه به‌صورت خودکار بر اساس تعداد روزهای کارکرد سرشکن نمی‌شود.

## اجرا از کد Python

Python 3.11 یا جدیدتر را نصب کنید. Tkinter و SQLite همراه Python ارائه می‌شوند؛ برای اجرای برنامه به نصب کتابخانه‌ی پایتون یا اتصال اینترنت نیاز نیست.

در پوشه‌ی برنامه اجرا کنید:

```text
python app.py
```

## دانلود برنامه‌ی نصبی ویندوز

از [صفحه‌ی انتشار GitHub](https://github.com/AmirAli800/catering-payroll/releases/latest) فایل `CateringPayroll-Setup-1.9.0.exe` را دریافت و اجرا کنید. نصب‌کننده برنامه‌ی درحال‌اجرا را هنگام به‌روزرسانی می‌بندد، میان‌بر منوی Start می‌سازد و امکان ساخت میان‌بر دسکتاپ را دارد. برنامه پس از نصب برای اجرا به اینترنت یا نصب Python نیاز ندارد.

## ساخت دستی فایل اجرایی و نصاب ویندوز

ساخت فایل‌های ویندوز باید روی ویندوز انجام شود. دوبار روی `build_windows.bat` بزنید:

1. فایل اجرایی مستقل `dist\CateringPayroll.exe` ساخته می‌شود.
2. اگر Inno Setup 6 نصب باشد، فایل نصبی `output\CateringPayroll-Setup-1.9.0.exe` هم تولید می‌شود.
3. اگر Inno Setup نصب نباشد، فقط فایل اجرایی ساخته و روش ساخت نصاب نمایش داده می‌شود.

برای ساخت نصاب، Inno Setup 6 را نصب کنید و این فرمان را اجرا کنید:

```text
ISCC installer.iss
```

نصاب برنامه اطلاعات را پاک نمی‌کند. پایگاه‌داده در مسیر زیر قرار می‌گیرد:

```text
%LOCALAPPDATA%\CateringPayroll\payroll.sqlite3
```

## آزمون‌ها

از پوشه‌ی اصلی پروژه اجرا کنید:

```text
python -m unittest discover -s tests -v
```
