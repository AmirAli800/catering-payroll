# مدیریت حقوق کترینگ

برنامه‌ای کاملاً مستقل برای ویندوز با رابط فارسی، نوشته‌شده با Python و Tkinter. این پروژه به سایت، Electron، مرورگر یا اینترنت وابستگی ندارد. اطلاعات کارکنان و پرداخت‌ها در یک پایگاه‌داده‌ی محلی SQLite روی رایانه ذخیره می‌شوند.

## امکانات

- ثبت و ویرایش پیک، آشپز و سایر کارکنان
- ثبت چند پرداخت علی‌الحساب برای هر کارمند در هر ماه
- محاسبه‌ی خودکار مانده‌ی حقوق و جلوگیری از پرداخت بیشتر از مانده
- مرور ماه‌های مختلف، جست‌وجوی کارکنان و دفتر پرداخت‌ها
- بایگانی کارمند از ماه انتخاب‌شده و امکان فعال‌سازی مجدد
- حذف پرداخت اشتباه با تأیید کاربر
- رابط کاربری فارسی با تم سفید و طلایی و انیمیشن کوتاه
- نگه‌داری اطلاعات حتی پس از بستن برنامه

## اجرا از کد Python

Python 3.11 یا جدیدتر را نصب کنید. Tkinter و SQLite همراه Python ارائه می‌شوند؛ برای اجرای برنامه به نصب کتابخانه‌ی پایتون یا اتصال اینترنت نیاز نیست.

در پوشه‌ی `CateringPayroll` اجرا کنید:

```text
python app.py
```

## ساخت فایل اجرایی و نصاب ویندوز

ساخت فایل‌های ویندوز باید روی ویندوز انجام شود. دوبار روی `build_windows.bat` بزنید:

1. فایل اجرایی مستقل `dist\CateringPayroll.exe` ساخته می‌شود.
2. اگر Inno Setup 6 نصب باشد، فایل نصبی `output\CateringPayroll-Setup-1.0.0.exe` هم تولید می‌شود.
3. اگر Inno Setup نصب نباشد، فقط فایل اجرایی ساخته و روش ساخت نصاب نمایش داده می‌شود.

برای ساخت نصاب، Inno Setup 6 را نصب کنید و این فرمان را اجرا کنید:

```text
ISCC installer.iss
```

نصاب برنامه اطلاعات را پاک نمی‌کند. پایگاه‌داده در مسیر زیر قرار می‌گیرد:

```text
%LOCALAPPDATA%\CateringPayroll\payroll.sqlite3
```

## آزمون‌ها

از پوشه‌ی اصلی پروژه اجرا کنید:

```text
python -m unittest discover -s CateringPayroll/tests -t . -v
```
